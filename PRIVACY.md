# OpenClaw GoingEmail Privacy Policy

**App:** OpenClaw GoingEmail  
**Last updated:** 2026-08-29  
**Contact:** TheGoingEmail@gmail.com

This OAuth app is a personal automation helper for the account owner and household only (TheGoingEmail@gmail.com).

## Data accessed
- Gmail (read, modify, send) for invite handling and mail automation
- Google Calendar events for reminders and schedule checks

## How data is used
Data is used only to run the owner's local OpenClaw/Chopper automations (calendar reminders, invite sweeps, morning rundown, and related household helpers).

## Storage and sharing
- Tokens and derived state are stored on the owner's private machines.
- Data is not sold, rented, or used for advertising.
- Data is not shared with third parties except Google APIs required to provide the service.

## Retention and revocation
Access can be revoked anytime in Google Account > Security > Third-party access. After revocation, API access stops and local tokens should be deleted.
